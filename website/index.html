Features

Everything you need, nothing you don't

☀

Live Weather Data

Real-time weather information from Open-Meteo API. No API keys required, no registration needed.

🔑

Smart Caching

Results are cached locally to reduce API calls and provide instant responses for repeated queries.

🖤

Shell Integration

Seamlessly integrates with bash, zsh, and fish. Add weather prompts and status lines to your shell.

🌱

Ambient Mode

Run in the background for continuous weather updates. Perfect for desktop widgets and status bars.

🌐

Global Coverage

Search by city name, coordinates, or IP-based detection. Weather data for any location worldwide.

✅

Locale-Aware Units

Automatically uses Fahrenheit for US users and Celsius for everyone else. Works the way you expect.

How It Works

Get weather data in three simple steps

1

Install

Clone the repository and run ./install.sh to install TermCast globally on your system.

2

Query

Type termcast cityname to get instant weather data for any location worldwide.

3

Integrate

Add the weather function to your shell RC file for persistent access in every terminal session.

Shell Integration

Add weather to your prompt or status line

# Add to ~/.bashrc
weather() {
  termcast "$1"
}

# Optional: Auto-detect location
PS1='\u@\h $(termcast --short)\$ '
# Add to ~/.zshrc
weather() {
  termcast "$1"
}

# Optional: Weather in right prompt
RPROMPT='$(termcast --short)'
# Add to ~/.config/fish/config.fish
function weather
  termcast $argv
end

# Optional: Weather in fish prompt
function fish_prompt
  echo -n (termcast --short)' $ '
end
